# Hammad Mahmud, Digital Marketer: portfolio

Static portfolio site (plain HTML, CSS and JavaScript, no build step), hosted on Cloudflare Pages at https://hammad-mahmud.pages.dev/.

- `index.html`: the whole site
- `css/styles.css`, `js/main.js`, `js/live.js`: styles, interactions and the live thumbnail animations
- `assets/`: screenshots, images, resume PDF and link-preview image
- `robots.txt`, `sitemap.xml`, `llms.txt`: search engine and AI assistant files
- `_headers`: Cloudflare Pages security and caching headers

Cloudflare Pages settings: framework preset None, no build command, output directory `/`.
